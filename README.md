# โปรแกรมจัดเรียงและตัดเพลงเต้นแอโรบิคสำหรับแฟลชไดร์ฟ (Music Sorter & Trimmer for Flash Drive)

เว็บแอปพลิเคชันที่ออกแบบมาเพื่อให้คุณแม่ใช้งานได้ง่ายที่สุด สำหรับแก้ปัญหาการนำเพลงลงแฟลชไดร์ฟไปเปิดกับลำโพงเต้นแอโรบิคแล้วเพลงเล่นไม่เรียงลำดับ พร้อมฟังก์ชันตัดแต่งเพลง (Audio Trimmer) ในตัว

---

## จุดเด่นของระบบ
* **แก้ปัญหาเพลงไม่เรียง 100%:** เขียนไฟล์ลงแฟลชไดร์ฟแบบเรียงลำดับทีละไฟล์ (Sequential Write) และกำหนด Prefix `001 - `, `002 - ` เพื่อบังคับตาราง FAT32 ของชิปลำโพงให้อ่านเพลงเรียงลำดับอย่างถูกต้อง
* **ระบบตัดต่อครอปเพลงในตัว (In-Browser Trimmer):** ตัดช่วงอินโทรที่เงียบ ตัดเสียงคนพูดเปิดคลิป หรือเลือกเฉพาะท่อนเต้นได้ทันที พร้อมตัวเลือก Fade-in / Fade-out นุ่มๆ ทำงานในเครื่อง 100% รวดเร็วใน 1-2 วินาที
* **ออกแบบเพื่อคุณแม่:** ตัวหนังสือใหญ่ (Sarabun font), สีสันชัดเจน, ปุ่มกดขนาดใหญ่, ฟังตัวอย่างเพลงได้ และมีทั้งการลากสลับลำดับและปุ่มลูกศร [▲] [▼]
* **ติดตั้งเป็นแอปบนหน้าจอคอมพิวเตอร์ได้ (PWA):** กดปุ่ม "ติดตั้งลงหน้าจอคอม" เพื่อให้มีไอคอนบนหน้าจอ Desktop ดับเบิ้ลคลิกเปิดใช้งานได้เหมือนโปรแกรมปกติ และอัปเดตให้อัตโนมัติ

---

## ขั้นตอนการใช้งาน
1. **ขั้นตอนที่ 1:** เสียบแฟลชไดร์ฟ และกดปุ่ม **"เปิดโฟลเดอร์ในแฟลชไดร์ฟ"** (หรือเลือกไฟล์จากในเครื่อง)
2. **ขั้นตอนที่ 2:** จัดเรียงลำดับเพลงตามต้องการ (กดฟังตัวอย่าง [▶], ลากสลับตำแหน่ง หรือกดปุ่มลูกศร [▲] [▼]) และกด **[ตัดเพลง]** เพื่อตัดหัว-ท้ายหากต้องการ
3. **ขั้นตอนที่ 3:** กดปุ่ม **"บันทึกลงแฟลชไดร์ฟ (เรียงตามลำดับนี้ทันที)"** รอระบบเขียนไฟล์จนครบ 100% แล้วนำแฟลชไดร์ฟไปเปิดกับลำโพงได้ทันที

## การรันและทดสอบระบบ

### การติดตั้ง Dependencies
```bash
npm install
```

### การเปิดใช้งานในโหมด Development
```bash
npm run dev
```

### การบิลด์สำหรับ Deploy (GitHub Pages / Vercel / Cloudflare Pages)
```bash
npm run build
```
ไฟล์ที่พร้อมใช้งานจะอยู่ในโฟลเดอร์ `dist/` ซึ่งเป็น Static Files ทั้งหมด สามารถนำไปโฮสต์ได้ฟรี 100%

## เทคโนโลยีที่ใช้ (Tech Stack)
* **Vite + React 19 + TypeScript**
* **Tailwind CSS**
* **Native File System Access API** (Chrome / Edge)
* **Web Audio API + Canvas Waveform**
* **@breezystack/lamejs** (In-Browser MP3 Encoder)
* **vite-plugin-pwa** (Progressive Web App)
