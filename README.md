# โปรแกรมจัดเรียงและตัดต่อเพลงสำหรับแฟลชไดร์ฟ (Music Sorter & Trimmer for Flash Drive)

🌐 **เว็บไซต์พร้อมใช้งาน:** [https://music.plazedez.online](https://music.plazedez.online)

เว็บแอปพลิเคชันสำหรับจัดเรียงลำดับเพลงลงแฟลชไดร์ฟ (USB) เพื่อแก้ปัญหาการนำเพลงไปเปิดกับเครื่องเล่น MP3 หรือลำโพงพกพาแล้วเล่นไม่เรียงตามลำดับ พร้อมระบบตัดต่อเพลง (Audio Trimmer) และประมวลผลไฟล์เสียงบนเบราว์เซอร์โดยตรง 100%

---

## จุดเด่นของระบบ
* **แก้ปัญหาเพลงไม่เรียง 100%:** เขียนไฟล์ลงแฟลชไดร์ฟแบบเรียงลำดับทีละไฟล์ (Sequential In-Place Write) และกำหนด Prefix `001 - `, `002 - ` เพื่อบังคับตาราง FAT32 ของชิปลำโพงให้อ่านเพลงเรียงลำดับอย่างถูกต้อง
* **ระบบตัดต่อเพลงในตัว (In-Browser Trimmer):** ตัดช่วงอินโทรหรือท่อนที่ไม่ต้องการ พร้อมตัวเลือก Fade-in / Fade-out ทำงานแบบ Client-side 100% รวดเร็วและปลอดภัย
* **ส่วนต่อประสานที่เรียบง่าย:** ตัวหนังสือขนาดใหญ่ สบายตา (Sarabun font), มีทั้งการลากสลับแถวและปุ่มลูกศร [▲] [▼], มีเครื่องเล่นเสียงตัวอย่างในตัว
* **รองรับทุกเบราว์เซอร์:** มีระบบตรวจจับและแจ้งเตือนเบราว์เซอร์ พร้อมโหมดสำรองดาวน์โหลดเป็นไฟล์ ZIP สำหรับ Safari, Firefox และ Brave
* **ติดตั้งเป็นแอปพลิเคชันได้ (PWA):** รองรับการติดตั้งลงหน้าจอ Desktop สำหรับเปิดใช้งานได้โดยตรงเหมือนโปรแกรมทั่วไป

## ขั้นตอนการใช้งาน
1. **ขั้นตอนที่ 1:** เสียบแฟลชไดร์ฟ และกดปุ่ม **"เปิดโฟลเดอร์ในแฟลชไดร์ฟ"** (หรือเลือกไฟล์จากในเครื่อง)
2. **ขั้นตอนที่ 2:** จัดเรียงลำดับเพลงตามต้องการ (กดฟังตัวอย่าง [▶], ลากสลับตำแหน่ง หรือกดปุ่มลูกศร [▲] [▼]) และกด **[ตัดเพลง]** เพื่อตัดหัว-ท้ายหากต้องการ
3. **ขั้นตอนที่ 3:** กดปุ่ม **"บันทึกลงแฟลชไดร์ฟ (เรียงตามลำดับนี้ทันที)"** รอระบบเขียนไฟล์จนครบ 100% แล้วนำแฟลชไดร์ฟไปเปิดกับลำโพงได้ทันที

## การรันและทดสอบระบบ

### การติดตั้ง Dependencies
```bash
npm install
```

### การเปิดใช้งานในโหมด Development
```bash
npm run dev
```

### การบิลด์สำหรับ Deploy (GitHub Pages / Vercel / Cloudflare Pages)
```bash
npm run build
```
ไฟล์ที่พร้อมใช้งานจะอยู่ในโฟลเดอร์ `dist/` ซึ่งเป็น Static Files ทั้งหมด สามารถนำไปโฮสต์ได้ฟรี 100%

## เทคโนโลยีที่ใช้ (Tech Stack)
* **Vite + React 19 + TypeScript**
* **Tailwind CSS**
* **Native File System Access API** (Chrome / Edge)
* **Web Audio API + Canvas Waveform**
* **@breezystack/lamejs** (In-Browser MP3 Encoder)
* **vite-plugin-pwa** (Progressive Web App)
